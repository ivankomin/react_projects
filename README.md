# React Projects Collection

A unified repository containing various React web applications. This collection serves as a workspace for implementing and practicing different frontend development concepts, including state management, routing, and API integration.

## Projects in this Repository

* **[WorldWise](./worldwise):** A Single Page Application for tracking traveled cities and countries. Features interactive maps (Leaflet), URL state management, React Router, and the Context API.
* **[usePopcorn](./usePopcorn):** A client-side movie library application for searching and tracking movies. Focuses on fetching data from an external API, using `useEffect`, and managing state with custom hooks.

## General Tech Stack

While each project may have specific dependencies, the applications in this repository generally utilize:

* **Framework:** React
* **Build Tool:** Vite
* **Language:** JavaScript / TypeScript
* **Routing:** React Router
